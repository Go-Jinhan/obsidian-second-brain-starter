# 검증 기록

검증일: 2026-11-06. 대상 버전: 0.1.0.

## 자동 검사

`npm run package`로 TypeScript 검사, 25개 테스트, 배포 빌드를 실행했다.

- 최상위·별도 폴더·중첩 폴더·기존 Organize 폴더 아래의 설치와 내부 링크 연결.
- 안내 17종의 두 언어 버전, 선택형 템플릿과 배너를 포함한 57개 파일 구성.
- 재설치 시 수정된 기존 파일 보존, 경로 충돌 시 쓰기 전 중단, 설치 도중 생긴 파일 보존.
- 쓰기 실패 이후 누락된 파일만 추가하는 재시도.
- 다섯 가지 노트 종류와 두 언어의 내용 생성, YAML 출처 속성, 제목 중복 처리.
- 볼트 외부·숨김 설정 폴더·링크를 깨뜨리는 문자가 포함된 설치 경로 거부.

## 실제 Obsidian 확인

macOS, Obsidian 1.15.0에서 별도 앱 프로필과 테스트 볼트를 사용했다. 개인 볼트의 노트로 테스트하지 않았다.

- 플러그인 로드 후 명령 세 개가 등록되고, 설치 전 노트 파일 수는 0개였다.
- 설치 화면에서 57개 추가를 미리 확인한 뒤 설치하고 영어 Welcome 안내가 열리는 것을 확인했다.
- 영어 노트 생성 화면에서 프로젝트를 만들었다. 전용 폴더, 출처 속성, The Hemingway Bridge를 포함한 본문을 확인했다.
- 재설치 결과는 신규 0개·건너뜀 57개였으며 기존 Welcome 내용은 같았다.
- 한국어 노트 생성 화면에서 참고 자료를 만들었다. 한국어 요약 콜아웃과 한글 출처가 정상 저장됐다.
- 같은 제목으로 다시 만들면 `(2)`가 붙었다.
- 플러그인을 비활성화해도 생성된 60개 파일이 유지됐고, 다시 활성화할 수 있었다.
- 마지막 개발자 오류 조회에는 오류가 없었다.

## 검증 범위

모바일 기기와 최소 지원 버전 1.14.4에서의 직접 실행은 아직 확인하지 않았다. 선택형 Templater·Periodic Notes의 별도 설치와 실행은 이번 플러그인 실행 검증에 포함하지 않았다.

## 커뮤니티 자동 검토

2026-11-06(KST)에 0.1.0의 검토가 Completed로 완료됐다. 공개 페이지의 Review는 Satisfactory, Health는 Excellent다. 등록을 막는 오류는 없었다.

- 네트워크·의존성 검사 통과.
- 소스에서 다시 빌드한 `main.js`가 릴리스 파일과 바이트 단위로 일치했다.
- 정규식의 제어 문자·불필요한 이스케이프 및 타입 단언에 린트 경고가 있다.
- 설정 화면을 선언형 API로 바꾸고 `display()` 대신 `update()`를 사용하라는 경고가 있다. 현재 설정은 동작하지만 Obsidian 설정 검색에는 노출되지 않는다.
- 배포 파일의 GitHub 출처 증명 추가와 부가 ZIP 첨부에 권고가 있다. ZIP은 수동 설치용이며 Obsidian의 자동 설치에는 사용되지 않는다.
