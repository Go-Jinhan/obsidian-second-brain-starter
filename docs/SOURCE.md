# 포함된 볼트 자료

기준: Go-Jinhan/obsidian-second-brain-template, 커밋 121772e.
개인 노트 없이 설명 노트·가상 예시·템플릿·배너만 포함한다.
README는 플러그인에서 설치한 사용자를 위한 Welcome 노트로 제공한다.
.obsidian 설정과 다른 플러그인의 실행 파일은 가져오지 않는다.
설계 안내의 두 언어 출처 목록에 『세컨드 브레인 2.0』(The PARA Method)을 보완했다.

플러그인과 직접 작성 자료는 소유자의 동의로 MIT 라이선스를 적용해 공개했다. 인용문·상표는 NOTICE.md에서 구분한다. 최초 공개와 커뮤니티 제출 정보는 SUBMISSION.md에 기록한다.
