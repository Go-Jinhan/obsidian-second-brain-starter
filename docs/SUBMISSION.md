# 최초 제출안

- 플러그인 이름: Second Brain Starter
- 식별자: `second-brain-starter`
- 공개 저장소 예정: `Go-Jinhan/obsidian-second-brain-starter`
- 첫 버전: `0.1.0`
- 설명: Set up a CODE, PARA, and Zettelkasten workspace and create notes in English or Korean.
- 라이선스 제안: MIT. 직접 작성 자료와 코드에 적용하며, 인용문·상표는 제외한다.
- 포함 자료: 설명 노트, 가상 예시, 선택형 템플릿, 배너와 시작 안내. 개인 볼트의 노트와 설정은 포함하지 않는다.
- 설치: 선택한 볼트 내부 폴더에 추가하며 기존 파일을 덮어쓰지 않는다.
- 통신: 네트워크 요청·텔레메트리·자동 종속 플러그인 설치 없음.

## 등록 양식에서 확인할 내용

제출자는 개발자 정책에 동의하고, 계속 지원하거나 더 이상 지원할 수 없을 때 플러그인을 내리거나 이전하겠다는 항목에 동의해야 한다.

공개 저장소 생성, MIT 라이선스 적용, 릴리스 게시와 위 동의를 포함한 커뮤니티 제출의 최종 확인이 남아 있다. 이 문서는 제출안이며 등록 완료를 의미하지 않는다.
