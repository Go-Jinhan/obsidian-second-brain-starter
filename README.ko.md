# Second Brain Starter

[English](README.md) · **한국어**

![Obsidian으로 연결되는 노트](vault/assets/second-brain-banner-obsidian.png)

메모는 많이 모았는데, 정작 필요할 때 어디서부터 찾아야 할지 막막할 때가 있습니다. Second Brain Starter는 모아둔 정보를 생각과 작업에 활용할 수 있도록 Obsidian 안에 폴더 구조, 설명 노트, 새 노트 만들기 기능을 마련해줍니다.

*CODE 기법*으로 정보를 활용하는 흐름을 만들고, *PARA 분류법*으로 지금 쓰임에 맞는 자리를 정합니다. *제텔카스텐 노트 작성법*은 자료에서 얻은 생각을 자신의 말로 설명하고 다른 생각과 연결하는 데 사용합니다. 각 설명 노트에는 폴더의 역할과 사용 예시를 담았습니다. 한국어와 영어로 읽을 수 있습니다.

## 메모 하나부터 시작하세요

1. 플러그인을 켜고 명령 팔레트에서 **Second Brain Starter: Set up workspace**를 실행합니다.
2. 한국어 또는 영어와 설치 위치를 고릅니다. 기본값은 `Second Brain` 폴더입니다. 빈 볼트의 최상위에 설치하려면 폴더 입력란을 비워둡니다.
3. 추가될 파일 수를 미리 확인한 뒤 **없는 파일 설치하기**를 누릅니다.
4. 시작 안내를 읽고 **Second Brain Starter: Create note**로 생각 하나를 기록하거나 프로젝트를 시작합니다.

설명 노트는 두 언어가 함께 설치됩니다. 언어 설정은 처음 열 안내와 앞으로 만드는 노트의 본문을 결정하며, 플러그인 설정에서 바꿀 수 있습니다.

## 지금 하는 일에 맞춰 정보를 놓습니다

**Capture**는 떠오른 생각과 참고 자료를 우선 받아두는 곳입니다. **Organize**에서는 프로젝트, 관리 영역, 관심 자료, 보관 자료로 쓰임을 구분합니다. **Express**에는 발전시킨 생각과 결과물을 쌓아갑니다.

*Distill*은 각 노트의 맨 위에 둡니다. 나중에 다시 열었을 때 무엇이 중요한지 빠르게 알아볼 수 있는 짧은 요약입니다. 별도 폴더를 거치게 만들 필요가 없습니다.

프로젝트를 시작하면 흩어져 있던 관련 자료를 프로젝트 폴더로 가져와 함께 사용합니다. 일이 끝나면 다시 쓸 자료는 Resources로 옮기고, 진행 과정과 결과는 프로젝트와 함께 Archives에 보관합니다. 프로젝트 노트의 *Twyla Tharp First Memo*에는 처음의 목적과 생각을, *Project Progress*에는 진행 내용을, *The Hemingway Bridge*에는 다음에 이어서 할 일을 남깁니다.

Resources의 번호와 주제별 서가는 *CMDS 지식 관리 방식*을 참고한 예시입니다. 모든 폴더를 채울 필요는 없습니다. 자신의 관심사에 맞게 이름을 바꾸거나 줄여서 사용하세요.

## 설치되는 내용

- 폴더와 핵심 개념을 설명하는 안내 17종의 한국어·영어 버전. 출처 속성과 관련 노트 연결을 포함합니다.
- 메모가 프로젝트와 영구 노트로 이어지는 모습을 보여주는 가상 예시.
- 시작 안내와 언어별 선택형 템플릿 6종.
- 떠오른 생각, 참고 자료, 책, 프로젝트, 영구 노트를 만드는 기능. 입력한 출처는 `source` 속성에 저장하고, 책과 프로젝트에는 각각 전용 폴더를 만듭니다.

명령은 **Set up workspace**, **Create note**, **Open welcome guide** 세 가지입니다. 다른 커뮤니티 플러그인 없이 사용할 수 있습니다. 포함된 `TPL -` 템플릿을 직접 실행하려면 Templater를 별도로 설치하세요. 일간·주간·월간 기록에 Periodic Notes를 연결하는 방법도 시작 안내에 적었습니다.

## 기존 노트와 함께 사용할 수 있습니다

플러그인을 켜는 것만으로 폴더가 생기지는 않습니다. 설치 화면에서 추가될 파일을 확인하고 실행합니다. 이미 있는 파일은 건너뛰므로 수정해둔 설명 노트도 그대로 유지됩니다. 같은 경로에 파일과 폴더가 충돌하면 설치를 멈추고 위치를 알려줍니다.

같은 제목으로 새 노트를 만들면 뒤에 번호를 붙입니다. 모든 내용은 일반 마크다운 파일로 남으며, 플러그인을 끄거나 삭제해도 만든 노트는 사라지지 않습니다.

플러그인은 오프라인으로 동작하며 네트워크 요청이나 사용 정보 수집을 하지 않습니다. 외부 출처는 직접 눌러 여는 링크입니다. 다른 플러그인을 설치하거나 켜지 않으며, 자신의 환경 설정은 Obsidian의 플러그인 설정 API로 저장합니다.

## 설치 방법

수동으로 설치하려면 공개된 릴리스에서 `main.js`, `manifest.json`, `styles.css`를 받아 `<볼트>/.obsidian/plugins/second-brain-starter/`에 넣으세요. Obsidian을 다시 불러오고 **설정 → 커뮤니티 플러그인**에서 **Second Brain Starter**를 켭니다. 직접 빌드하면 같은 세 파일이 `dist/second-brain-starter/`에 만들어집니다.

커뮤니티 디렉터리에 공개된 뒤에는 **설정 → 커뮤니티 플러그인 → 탐색**에서 **Second Brain Starter**로 검색할 수 있습니다. GitHub에 릴리스만 올린 상태에서는 이 검색에 나타나지 않습니다.

Obsidian 1.14.4 이상이 필요합니다. macOS의 Obsidian 1.15.0에서 확인했습니다. 여러 플랫폼에서 사용할 수 있는 Obsidian API로 구현했으며, 모바일 기기에서는 아직 확인하지 않았습니다.

## 참고 자료와 개발

볼트 구성은 [Obsidian Second Brain Template](https://github.com/Go-Jinhan/obsidian-second-brain-template)을 바탕으로 합니다. 설계 안내에서 티아고 포르테의 『세컨드 브레인』과 『세컨드 브레인 2.0』, *제텔카스텐*, *CMDS*가 각각 어떤 역할을 하는지 설명하고 출처로 연결합니다. 예시에는 개인 기록을 사용하지 않았습니다.

Node.js 22 이상에서 다음 명령으로 빌드합니다.

```sh
npm ci
npm run package
```

타입 검사와 설치·노트 생성 검사를 거쳐 배포 파일을 만듭니다. 자세한 내용은 [검증 기록](docs/TESTING.md)과 [배포 절차](docs/RELEASING.md)를 참고하세요.
